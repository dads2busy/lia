{
  "nodes": [

* **id**  = 6-digit HS 2022 heading of that stage (use the most specific 6-digit code that explicitly names or implies the material).

**Styling constraints**

* Do **NOT** wrap the JSON in extra commentary—only the code block plus the HS-code reference bullets.  
* Keep the JSON human-readable (indent with two spaces).
